# Usuwanie danych w MediApp

## W aplikacji (zalecane)

1. Otwórz **Ustawienia**.
2. Wybierz **Usuń wszystkie dane**.
3. Potwierdź komunikat.

Efekt:

- Usunięte tabele IndexedDB: `medications`, `doseLogs`, `gamification`, ustawienia (w tym zgody RODO).
- Przekierowanie do onboardingu i ponownej zgody przy następnym użyciu.

## Czego aplikacja nie usuwa

- Pliki eksportu CSV/PDF zapisane przez Ciebie poza aplikacją (np. folder Pobrane).
- Dane w kopii zapasowej przeglądarki / synchronizacji systemowej — zależą od producenta urządzenia.

## Cofnięcie zgody

Usuń dane jak powyżej i przestań korzystać z MediApp. Bez zgody aplikacja nie powinna być używana do przechowywania nowych wpisów.

## Przeglądarka

Możesz też wyczyścić dane witryny dla `memphistor.github.io` w ustawieniach przeglądarki — skutek jak usunięcie lokalnej bazy.
