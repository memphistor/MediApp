# Deklarowane przeznaczenie (szkic do konsultacji regulacyjnej)

**Produkt:** MediApp — osobisty dziennik i przypominacz.

**Użytkownik:** Osoba dorosła zapisująca własne informacje o przyjmowanych produktach (leki, suplementy).

**Zasada:** Użytkownik wpisuje, aplikacja zapamiętuje i przypomina. Aplikacja **nie ocenia**, **nie podpowiada medycznie** i **nie ostrzega** na podstawie wiedzy o lekach.

## Funkcje w MVP (szkielet) — ocena robocza

| Funkcja | Zachowanie | Wiedza medyczna? |
|---------|------------|------------------|
| Kreator pozycji | Puste/neutralne pola, użytkownik wypełnia | Nie |
| Harmonogram | Użytkownik definiuje częstotliwość i godziny | Nie |
| Przypomnienia (faza 2) | Treść z pól użytkownika | Nie |
| Widok dnia / historia | Odtwarza zapisy | Nie |
| Gamifikacja | Liczy odhaczenia planowych dawek (seria, odznaki, pierścień dnia) — bez oceny zdrowia | Nie |
| Eksport PDF/CSV (faza 3) | Suchy raport zapisów | Nie |
| Etykieta „na co przyjmujesz” | Tekst użytkownika, bez walidacji | Nie |

## Świadomie poza zakresem

- Wykrywanie interakcji lub duplikatów substancji
- Sugestie dawkowania / „na czczo” z bazy leków
- Autouzupełnianie dawki lub sposobu przyjmowania z bazy
- Chat AI w sprawach łączenia leków
- Komunikaty typu „terapia prawidłowa” lub „bezpieczny harmonogram”

## Komunikacja marketingowa i w sklepie

Używać: *osobisty dziennik*, *przypominacz*, *własne notatki*.

Unikać: *bezpieczne przyjmowanie*, *zapobiega interakcjom*, *poprawia skuteczność terapii*.

## RODO

Nazwy produktów i etykiety zdrowotne mogą stanowić dane szczególnej kategorii (art. 9). W MVP: przechowywanie lokalne, eksport i usunięcie danych w ustawieniach; pełna polityka prywatności przed publikacją.
